\# HelloApp Use Case Documentation



This document contains the use case descriptions for the HelloApp project.



\## UC1: Display Hello World

Print a basic greeting message in the console.



\## UC2: Display User Name

Accept a name via command-line arguments and greet the user.



\## UC3: Optional Argument Handling

Provide a default greeting if no name is provided.



\## UC4: Multiple Command-line Names

Allow greeting multiple users in a single execution.



\## UC5: Read Name from Standard Input

Accept user input from the keyboard.



\## UC6: Multiple Names from Standard Input

Allow multiple names to be entered.



\## UC7: Store Names in Memory

Store entered names in a collection and list them.



\## UC8: Remove Names

Allow deletion of stored names.



\## UC9: Refactor into Methods

Move logic into reusable methods.



\## UC10: Separate Class for Name Management

Create a class responsible for managing names.



\## UC11: Persist Names

Save names to storage and load them across runs.



\## UC12: Banner Display

Display names in a banner-style output.
